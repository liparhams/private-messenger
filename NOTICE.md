# Utinochat

Utinochat is an independent web messenger built with React, Vite and Supabase. Its interface and interaction patterns are inspired by Telegram's public web/desktop projects.

Reference projects:
- Telegram Web K (tweb)
- Telegram Web A (telegram-tt)
- Webogram
- Telegram Desktop

Those upstream projects are GPL-licensed. Utinochat does not claim to be the Telegram client or connect to Telegram's MTProto service. Upstream source and licenses remain with their respective authors.

## Run

npm install
npm run dev
