# UTINOCHATV1 UI/UX skills

This project uses the design direction from the upstream Taste Skill and UI UX Pro Max Skill for redesign work.

- Taste Skill: https://github.com/leonxlnx/taste-skill
- UI UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Project mode: modern messaging product, responsive first, accessibility-aware, compact but breathable, restrained motion, no generic AI-glow styling, and no emoji used as interface icons.

For local AI-agent installation, use the upstream installers documented by the projects. Do not ship these AI skills as browser/runtime dependencies.
