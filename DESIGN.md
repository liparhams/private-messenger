# Utino Chat v1 Design System

Utino Chat v1 is a public, modern messaging platform. The interface is original, using familiar messaging UX patterns without copying third-party branding, logos, or proprietary assets.

## Visual direction
- Premium, modern, calm messaging UI
- Clear hierarchy, rounded surfaces, purposeful whitespace
- Mobile-first responsive layout
- Persian RTL and English LTR
- Dark and light themes
- Accessible focus states and reduced-motion support

## Product UX
- Search by username, display name, and public ID
- One-tap start-message action
- Private conversations and multi-user group chats
- @mention autocomplete
- Per-message seen state and reader list
- Profile drawer/modal
- Dedicated support center
- Admin modal for creating users
